# MediBook Dashboard

React + Vite. Dashboard layout: CSS ცვლადები, CSS Grid (მაკრო-ლეიაუთი) და Flexbox (კომპონენტები).

## გაშვება

```bash
npm install
npm run dev
```

შემდეგ გახსენი ბრაუზერში ტერმინალში გამოსულ მისამართს (ჩვეულებრივ http://localhost:5173).
